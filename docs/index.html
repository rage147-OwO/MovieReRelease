    🔔 새 재개봉작 알림 받기

    매일 아침 자동으로 찾은 재개봉작 중, 어제까지 없던 새 작품만 디스코드로 알려드려요.

    1. 디스코드에서 알림 받을 채널 설정(⚙️) → 연동 → 웹후크 → 새 웹후크 → 채널 선택 → 웹후크 URL 복사
    2. 저장소 Settings → Secrets and variables → Actions ↗ 로 이동
    3. New repository secret 클릭 → Name에 DISCORD_WEBHOOK_URL, Value에 복사한 웹후크 URL 붙여넣기 → Add secret

    다음 자동 갱신(매일 06:00)부터 적용돼요. 지금 이 설정은 사이트 운영자만 할 수 있고, 방문자별로 각자 알림을 구독하는 기능은 아직 없어요.
