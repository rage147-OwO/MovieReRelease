    🔔 새 재개봉작 알림 받기

    매일 아침 자동으로 찾은 재개봉작 중, 어제까지 없던 새 작품만 알려드려요.

    방법 1 — RSS로 받기 추천 · 더 쉬움

    누구나 자기 디스코드 서버에서 바로 구독할 수 있어요. 시크릿 설정 필요 없음.

    1. 디스코드 서버에 MonitoRSS ↗ 같은 RSS 봇 추가 (무료)
    2. 봇 명령어(예: /rss add)로 아래 피드 주소 등록
      https://rage147-owo.github.io/MovieReRelease/feed.xml

    방법 2 — 웹훅으로 직접 받기

    사이트 운영자만 설정 가능. GitHub Secret 등록이 필요해요.

    1. 디스코드에서 알림 받을 채널 설정(⚙️) → 연동 → 웹후크 → 새 웹후크 → 채널 선택 → 웹후크 URL 복사
    2. 저장소 Settings → Secrets and variables → Actions ↗ 로 이동
    3. New repository secret 클릭 → Name에 DISCORD_WEBHOOK_URL, Value에 복사한 웹후크 URL 붙여넣기 → Add secret

    두 방법 다 다음 자동 갱신(매일 06:00)부터 적용돼요.
